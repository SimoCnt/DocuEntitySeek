# DocuEntitySeek

DocuEntitySeek è una piattaforma di document intelligence dedicata
all'analisi di contratti, bandi e documenti di gara.

## Funzionalità principali

- Entity Discovery
- Structured Field Extraction
- annotazione delle entità nel documento
- provenienza delle informazioni estratte
- schema Procurement predefinito
- schemi personalizzati per utenti Premium

## Stack

### Frontend
- React
- TypeScript
- Vite

### Backend
- FastAPI
- Python 3.12

### AI
- PyMuPDF
- GLiNER2.5

### Database
- PostgreSQL
- SQLAlchemy

### Infrastructure
- Docker
- Docker Compose
